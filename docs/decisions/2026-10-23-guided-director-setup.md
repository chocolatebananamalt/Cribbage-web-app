from its persisted projections instead of a replacement wizard or stored
completion flags. Unknown/failed reads remain unknown; corrections may revoke
completion. Keep all existing server gates and exceptional tools visible.

date is not a time or an end date; require explicit values and give later saved

quota/IP errors have no client-invented duration. Preserve the password fallback
and the existing server authentication/authorization boundary. No provider
