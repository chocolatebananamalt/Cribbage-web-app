## Change

Ordinary Main Results now has an independently gated current selected-increment
pool-award panel for the existing primary Director only. It does not replace
legacy reports, team/Satellite handling, synthetic practice results or the old
$5 journal. No public/player access is added.

The new read-only SQL rebuilds current ownership, consent, policy, qualification,
fixed identity and independently saved Q/Side rounding under source locks. It
requires complete equality with the recorded final capture and proposal head,
then checks the exact persisted recipient set, participant identities, increments
and totals. Changed evidence is held; historical receipts never serve as current
proof. No own-final guard or existing writer was removed or replaced.

The authenticated server reader checks actual Director identity before and after
the injected trusted RPC. Both outer result and nested source must match the
qualification version already displayed by the Results page. The display retains
only saved pool labels, method/ratio, fund, increment, names, fixed Tournament IDs
and awards. It strips internal source pins, actor/participant/reviewer IDs and
private receipt captures. Everything is explicitly unpaid; no bank, payment,
MRP or ACC submission claim is made.

Labels come from immutable Q setup versions and current Side definitions rather
than global display indexes. Missing/invalid labels remain held. Independent
review found a preexisting column-variable ambiguity in the Side policy lookup;
it now binds the explicit pool UUID from the current source JSON.
