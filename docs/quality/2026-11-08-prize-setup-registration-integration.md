# Local Setup and registration integration

This is a private, default-disabled candidate, not a published replacement. No
hosted records, permissions, credentials or deployments were changed. Daron's
saved walkthrough was not read or modified during this work.

## Observable behavior

The optional normal Setup branch now authors the agreed Playoff series and V2
prize controls between Fee Includes and Payout Information. Existing Main and
Consolation policies require explicit adoption; historical declarations and
dormant V1 values remain intact. Only this new branch hides the old declaration
editors. Its save buttons retain and send one complete request containing the
setup, links, series and prize plans. There is no fallback to an older writer.

Recovery requires the complete actor/operation/hash-bound record, fresh saved
head and exact local request before cleanup. Unknown, foreign-account or
unrecognized retained work is preserved. A recorded rejection or superseded
save needs explicit resolution; transport/attempt errors do not prove rollback.
Ownership and recovery-coordinator permission are rechecked before I/O and
cleanup, including after asynchronous reads.

Finalization opens registration only. The Director reviews each event's actual
rule context. The exact reviews displayed, settings/prize snapshots, setup
revision and link hash bind the outer operation. Local edits or another
Director's review changes during confirmation invalidate confirmation. Only the
server constructs its privileged client, after the cookie user, current role
and owned preparation record are verified. Exact recovery works after a lost
response. All source, write and recovery routes and SQL wrappers remain closed
in the production composition; the page does not enable this branch.

## Limits and remaining gates

- No new payout amounts are calculated or disbursed by this path. Raw settings
  persistence is not evidence that every selected mathematical policy works.
- New-policy playoff execution, Finance/accounting and post-final event
  amendments are deliberately blocked, not silently routed to old calculations.
- Existing unsupported Custom-N pool sources fail closed in this root save
  composition; this checkpoint is not a claim of arbitrary-pool integration.
- The direct native-trigger legacy-series/V2-prize edge is source-reviewed but
  not a distinct runtime fixture; the old unpinned operational finalizer was
  tested and rejected.
- A real signed-in provider/session and independent-device acceptance, reviewed
  release dependency/migration package, current recovery preflight and scoped
  hosted/public-source approval are still required before live enablement.
- The previously denied registry audit was not retried or bypassed. Local
  verification components are recorded separately; no clean `pnpm verify`
  audit result is claimed.
